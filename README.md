# Ahmed Raza Portfolio

This repository contains the source code for my personal portfolio website.

## About

The portfolio presents my background, education, technical skills, projects, experience, certifications, and contact information. It highlights my work in AI and machine learning, full-stack development, and mobile application development with Flutter and React Native.

## Run Locally

```bash
npm install
npm start
```

The site will be available at `http://localhost:3000`.

## Build

```bash
npm run build
```

## Technology

- React
- JavaScript
- AI and machine learning
- Full-stack web development
- Flutter and React Native
